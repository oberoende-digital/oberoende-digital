# Policyanalys: Optimal försvarsbudget som andel av BNP

## 1. Sammanfattning

Sverige nådde 2 % av BNP 2025 (Nato-mål) och siktar på 2,4 % 2028. FOI (2023) bedömer att ~3 % skulle krävas för att återställa 1990 års försvarsförmåga realt. Historiskt: ~3,5 % under Kalla kriget. OD-position: 2,5-3 % av BNP med fokus på personal, cyber och luftvärn, översyn vart 5:e år baserat på hotbild.

Relevanta källor inkluderar myndighetsrapporter (se ovan), forskningsartiklar, och internationella jämförelser. Fullständig källförteckning uppdateras löpande.

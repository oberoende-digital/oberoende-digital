# Policyanalys: Obligatorisk tjänstepension?

## Metadata

- **Kategori:** Pension
- **Evidensnivå:** MEDIUM
- **Politisk laddning:** MEDIUM

---

## 1. Sammanfattning

Ca 90 % av anställda har tjänstepension via kollektivavtal. Glappet finns för egenföretagare, gig-arbetare, och anställda utan kollektivavtal. Pensionsmyndigheten (2023) uppskattar att ~500 000 saknar tjänstepension. OD-position: gör tjänstepension obligatorisk för alla arbetsgivare, med undantag för mikroföretag (färre än 3 anställda).

Relevanta källor inkluderar myndighetsrapporter (se ovan), forskningsartiklar, och internationella jämförelser. Fullständig källförteckning uppdateras löpande.
